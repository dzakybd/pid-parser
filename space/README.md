# pid-parser showcase

Precomputed results of [pid-parser](https://github.com/dzakybd/pid-parser) on three synthetic P&ID sheets: the drawing with what the model read, the graph, the tables, and the SQL, CSV, GraphML and Cypher exports. The page calls no model.

Install the skill in your own agent with `npx skills add dzakybd/pid-parser`.

Drawings: synthetic sheets from [PID2Graph](https://zenodo.org/records/14803338) ([paper](https://arxiv.org/abs/2411.13929)), CC BY-SA 4.0. The drawings and the outputs derived from them are shared under CC BY-SA 4.0. The pid-parser code is MIT licensed.
